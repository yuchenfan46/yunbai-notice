3. 香港服务器自动 DD 纯净重装指南 ＋

系统 DD 纯净重装指南

适用于云白平台香港机房服务器

避坑提示： 本站香港服务器自带的系统模板镜像目前存在一些已知的组件 Bug。为了保障您后续跑业务的绝对稳定，强烈建议您在控制台首次重装系统后，务必使用 SSH 连入服务器，自己通过一键脚本重新刷入纯净版系统。

第一步：拉取网络重装核心脚本

使用 SSH 工具连接服务器后，输入以下命令并回车拉取脚本：

curl -O https://raw.githubusercontent.com/bin456789/reinstall/main/reinstall.sh
# 若 curl 报错，可使用备用命令：
# wget -O reinstall.sh https://raw.githubusercontent.com/bin456789/reinstall/main/reinstall.sh

第二步：执行全自动化重装

请根据您的需求，修改下方代码中的中文提示部分为您自己的参数并执行：

bash reinstall.sh 你要装的系统名称 --password 你要设置的复杂密码 --ssh-port 自定义ssh端口

举例说明：
如果您想重装为 Debian 12，设置密码为 Yunbai@2026!，SSH 端口改为 2222，则命令为：
bash reinstall.sh debian-12 --password "Yunbai@2026!" --ssh-port 2222

🔗 支持的完整系统镜像名称列表，请前往官方开源地址查阅：点击此处访问

第三步：重启并等待

代码在终端跑完且无报错后，输入 reboot 重启服务器。系统会断开连接并在后台自动进行底层的格式化与重装。通常需等待 10~20 分钟左右，请使用新密码 and 新端口重新连接即可。
