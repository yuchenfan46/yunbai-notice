## 📢 广告限制

本群并非无门槛的广告广场。如果您想发布各类推广/AFF/接单广告，**必须满足以下两个条件之一**：

- **条件一：** 您的 QQ 群等级达到 **80 级及以上**的活跃账号。
- **条件二：** 若等级未达标，必须**提前私聊群主并取得本人的明文同意**。

::: danger 严重警告
任何违规发布未经授权的广告或引流链接的行为，一律撤回消息并直接送飞机票（踢出并拉黑），绝不姑息。
:::

我个人的精力极其有限，在这里明确划定支持边界：**本人仅对“云平台 yunbai.org 的商业服务器订单、账单、云资源硬件故障”提供一对一的技术支持。**

::: warning ⚠️ 公益项目免打扰协议
旗下所有的“公益项目”，均是我个人利用闲置算力和时间用爱发电搭建的。对于这些公益项目，除遇到导致服务全盘瘫痪的**严重 system Bug** 允许向我反馈外，其余任何关于“怎么配置”、“为什么连不上本地”、“能不能加功能”等琐碎技术盲区，**请自行使用搜索引擎解决，非严重 Bug 严禁私聊打扰，违者拉黑**。
:::
