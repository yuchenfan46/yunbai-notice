## 🙋 高频问题自助速查

- **🔌 SSH 连不上？**  
  先确认安全组 / 防火墙是否放行了您设置的 SSH 端口；若使用 DD 脚本重装过，请核对您在脚本中指定的新端口和新密码，旧凭据已全部失效。
- **🌐 网站 / 服务无法访问？**  
  依次排查：① Nginx/Apache 进程是否正常运行（`systemctl status nginx`）；② 端口是否被宝塔面板防火墙拦截；③ 域名 DNS 是否已正确解析至服务器 IP。
- **💳 账单扣费 / 续费问题？**  
  登录 [yunbai.org](https://yunbai.org) 后台，进入「财务」→「账单明细」自查。如有疑问，请带上订单号通过 IM 联系，口头描述无法核实。
- **⚡ 服务器性能跑分 / 测速？**  
  推荐使用 [融合怪测评脚本](https://github.com/spiritLHLS/ecs) 一键测速，结果直观全面，测完截图即可。
